# M1.6 — GPX track statistics

Status: implemented.

M1.6 extends GPX 1.1 track inspection with elevation and timestamp-derived statistics while keeping the existing local waypoint persistence format unchanged.

## Included

- optional GPX `<ele>` parsing for track points
- optional GPX `<time>` parsing using RFC3339 timestamps
- elevation point count
- minimum and maximum elevation
- cumulative elevation gain and loss
- timed point count
- activity duration from adjacent timed points
- average speed from distance covered by valid timed legs
- maximum speed from valid timed legs
- browser display through the existing GPX inspector
- JSON output through `POST /api/gpx/inspect`
- no provider account, API key or network dependency

## Segment semantics

All derived statistics respect GPX `<trkseg>` boundaries.

Distance, elevation gain/loss, duration and speed are never calculated across the gap between two track segments. This avoids artificial distance, elevation jumps or elapsed time caused by pauses or separate recordings.

## Partial metadata

Elevation and timestamps are optional in GPX. M1.6 therefore reports statistics only from the metadata that is actually present:

- `elevation_points` counts track points containing `<ele>`
- elevation gain/loss requires consecutive points that both contain elevation
- `timed_points` counts points containing valid RFC3339 `<time>` values
- duration/speed require consecutive points in the same segment with valid, strictly increasing timestamps
- missing metadata does not invalidate an otherwise valid track
- a real elevation value of `0` metres is preserved and not confused with missing elevation

Malformed non-empty timestamps are rejected instead of silently producing misleading statistics.

## Speed semantics

For every adjacent pair of timed points in a segment, Caching Tools calculates great-circle distance and divides it by the positive timestamp delta.

- `duration_s` is the sum of these valid timed intervals
- `average_speed_kmh` is total distance from valid timed intervals divided by `duration_s`
- `max_speed_kmh` is the largest per-interval speed

This is intentionally basic GPS statistics. It does not yet classify stopped versus moving time or smooth GPS noise.

## Persistence

Tracks and routes remain inspection-only in M1.6. Existing waypoint data under `/data` and GPX waypoint import/export are unchanged.
