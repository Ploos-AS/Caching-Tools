# M1.12 — Save intersection solutions as waypoints

Status: implemented.

M1.12 connects the coordinate-intersection toolbox to the existing local waypoint store.

## Scope

Each solution returned by the M1.11 intersection solvers can be saved directly as a waypoint:

- bearing / bearing
- bearing / distance
- circle / circle

The save action uses the existing `POST /api/waypoints` API and therefore the existing `/data/waypoints.json` persistence model. No new storage format or migration is introduced.

## Saved waypoint metadata

A saved solution receives:

- a deterministic descriptive name such as `Intersection circle-circle 1`
- waypoint type `intersection`
- the exact returned latitude and longitude
- a comment recording the source intersection type and solution number

## UI behavior

Every returned solution has a `Save solution N` button. After a successful save:

- the local waypoint list is refreshed
- the interactive local map is refreshed
- the saved solution is immediately available for normal waypoint edit/delete/export workflows
- the solution can be selected on the map like any other waypoint

## Offline behavior

The complete solve-and-save flow remains local. It does not require an account, API key, map provider, CDN or network connection.
