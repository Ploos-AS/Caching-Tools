# M1.27 — Live session statistics

M1.27 adds local statistics for the current in-memory live-navigation breadcrumb session.

## Scope

The browser computes statistics directly from the breadcrumb list created by live navigation. Nothing is written to `/data`, no backend schema changes are introduced, and the existing navigation API remains unchanged.

The session statistics panel reports:

- travelled distance from consecutive breadcrumb coordinates
- session duration from the first to the last breadcrumb timestamp
- timed movement accumulated only across positive, valid timestamp deltas
- average speed from travelled distance divided by timed movement
- maximum accepted segment speed
- count of accepted speed samples

Distance uses a WGS84-style spherical haversine calculation with the same mean Earth radius used elsewhere in Caching Tools (`6371008.8 m`).

## Defensive timing and speed handling

A segment contributes to distance regardless of timestamp quality, but speed statistics require a finite, positive timestamp delta.

For maximum-speed statistics, non-finite values, negative values and derived segment speeds above `100 m/s` (`360 km/h`) are ignored as obvious GPS/timestamp outliers for this hobby-navigation workflow. The UI states this explicitly.

Average speed uses all distance together with valid positive timed intervals. The filtering is intentionally conservative and is not intended as a survey-, fitness- or motorsport-grade motion model.

## Lifecycle

Statistics update every time a breadcrumb is added. Starting a new live-navigation session clears breadcrumbs and statistics. Clearing breadcrumbs manually also resets the statistics. Reloading the page removes the session because the breadcrumb state remains browser-memory only.

GPX export from M1.26 is unchanged and continues to export the original breadcrumb points and timestamps.

## Acceptance

- session distance is visible and updates from breadcrumb geometry
- duration is derived from first/last timestamps
- average and maximum speed are displayed in km/h
- invalid/non-positive time deltas do not produce invalid speed values
- extreme derived speeds above 360 km/h are excluded from maximum-speed statistics
- clearing/new session resets statistics
- no new backend API or persistent data format
- static asset regression covers the M1.27 statistics UI and helpers
