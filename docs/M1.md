# M1 — Coordinate toolbox

Status: implemented

## Goal

Turn the M0 shell into a useful, provider-independent geocaching coordinate tool.

## Acceptance criteria

- [x] Parse decimal degrees (DD).
- [x] Parse degrees and decimal minutes (DMM).
- [x] Parse degrees, minutes and seconds (DMS).
- [x] Validate latitude/longitude ranges and hemisphere use.
- [x] Render coordinates as DD, DMM and DMS.
- [x] Calculate great-circle distance between two points.
- [x] Calculate initial bearing between two points.
- [x] Expose conversion and navigation through JSON HTTP endpoints.
- [x] Provide usable web forms for both operations.
- [x] Cover parser, validation, formatting, navigation and HTTP behavior with Go tests.
- [x] Keep all M1 functionality local and API-key free.

## API

- `POST /api/coordinates/convert`
- `POST /api/coordinates/navigation`

## Explicitly deferred

- coordinate projection
- line/circle intersections
- UTM/MGRS
- GPX
- puzzle/cipher tools
- persistent cache/waypoint storage
- provider integrations

Projection is the natural next coordinate primitive because it complements distance and bearing and is common in multi-cache field work.
