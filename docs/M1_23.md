# M1.23 — Route progress and bearing guidance

M1.23 extends the local field-navigation toolbox with progress guidance for saved routes and tracks.

## Scope

For a current position and a saved route/track, `POST /api/navigation/field` now returns:

- nearest point on the selected path
- cross-track / nearest-path distance
- nearest segment and edge
- along-path distance already covered
- total path distance
- remaining path distance
- progress percentage
- next path point
- distance from the nearest path position to that next point
- forward bearing from the nearest path position toward the next point

Waypoint navigation remains unchanged and does not return path-progress fields.

## Segment semantics

Track segments remain independent. Distances are summed only inside each `<trkseg>`; no artificial distance is added across segment boundaries. Progress in a later segment includes the completed lengths of earlier segments, but not the geographic gap between them.

Route paths are treated as one continuous point sequence.

## Geometry

Nearest-point projection uses the same local tangent/equirectangular approximation introduced for M1.22 nearest-path calculations. Distances and bearings exposed to the user continue to use the existing great-circle helpers.

The progress value is derived from the fractional position on the nearest edge. It is intended for hobby GPS and field guidance, not survey-grade navigation.

## UI

The Field navigation panel now shows, for route/track targets:

- progress percentage
- along / total distance
- remaining distance
- next-point coordinate
- distance to next point
- forward bearing

Manual current-position entry, browser geolocation and map-selection target linkage remain available.

## Persistence and dependencies

- no new persistent files
- no schema migration
- no map tile/provider dependency
- no API key
- no external geodesy library

## Acceptance
