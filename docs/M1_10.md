# M1.10 — Interactive local map

Status: implemented.

M1.10 upgrades the M1.9 local SVG overview into an interactive, still fully local map for saved waypoints, routes and tracks.

## Included

- drag-to-pan interaction
- mouse-wheel zoom
- explicit zoom in/out controls
- fit-all control
- fit-to-selection control
- clickable waypoint, route and track objects
- keyboard activation of selectable SVG objects with Enter/Space
- visual selection state on the map
- selected object label below the map
- selected map object linked to the matching waypoint/path row
- smooth scroll to the matching saved-data row
- full track segment boundaries preserved
- existing `/data/paths.json` representation remains compatible
- no external map tile provider, CDN, account, API key or network dependency

## View model

The map remains a schematic local coordinate view rather than a geographic basemap. Coordinates are projected into an SVG viewport based on the bounds of the locally saved data.

Pan and zoom change only the SVG `viewBox`; stored GPS data is not modified.

`Fit all` restores the complete local-data extent. `Fit selection` uses the bounds of the selected waypoint, route or track.

## Selection and list linkage

Waypoints and path polylines are interactive SVG elements with keyboard focus. Selecting an object:

1. marks it visually on the map,
2. updates the selected-object label,
3. emits the local `caching-tools:map-select` browser event,
4. highlights and scrolls to the corresponding saved-data row.

This keeps map interaction decoupled from persistence and API contracts.
