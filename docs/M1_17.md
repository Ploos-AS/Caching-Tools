# M1.17 — Mystery workspace integration

M1.17 turns the persistent mystery workspace into the active working context for puzzle solving.

## Included

- choose a saved mystery workspace with **Use in solver**
- load workspace A–Z variables into the existing final-coordinate solver
- load workspace latitude and longitude formulas into the final-coordinate solver
- puzzle helpers publish their latest rendered result to the active workspace integration panel
- add the latest puzzle result as an intermediate result
- extract a numeric value from the latest puzzle result and store it as an A–Z workspace variable
- saving a solved final still creates a normal persistent waypoint
- when a workspace is active, the new final waypoint is automatically linked back through `final_waypoint_id`
- final waypoint names include workspace GC code/title when available
- no schema migration: existing `/data/mystery-workspaces.json` remains valid
- no external provider, account, API key or network dependency

## Workflow

1. Create or open a mystery workspace.
2. Click **Use in solver**.
3. Use puzzle helpers as needed.
4. Add the latest helper result to the workspace, or assign its first numeric value to an A–Z variable.
5. The final-coordinate solver receives workspace variables and formulas directly.
6. Save the solved final as a waypoint.
7. The waypoint ID is written back to the active workspace automatically.

## Persistence

M1.17 does not add a new persistent format. Workspaces continue to use `/data/mystery-workspaces.json`; waypoints continue to use `/data/waypoints.json`.
