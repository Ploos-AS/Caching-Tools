# M1.22 — Field navigation toolbox

M1.22 adds local field-navigation helpers that work with the waypoint and route/track data already stored by Caching Tools.

## API

`POST /api/navigation/field`

Request:

```json
{
  "from": {"latitude": "59.9139", "longitude": "10.7522"},
  "waypoint_id": "wp-..."
}
```

or:

```json
{
  "from": {"latitude": "59.9139", "longitude": "10.7522"},
  "path_id": "path-..."
}
```

Exactly one target ID is required.

For a waypoint, the response contains great-circle distance and initial bearing to that saved waypoint.

For a route or track, Caching Tools searches every stored segment for the nearest point and returns:

- nearest coordinate on the path
- distance and bearing from the supplied position to that point
- cross-track / nearest-path distance
- zero-based segment and edge indexes identifying the nearest path section

The nearest-point calculation uses a local tangent-plane projection per path edge and great-circle distance for the final distance/bearing measurement. It is intended for practical GPS/hobby field use, not survey-grade geodesy.

## UI

The **Field navigation** panel:

- loads saved waypoints and routes/tracks
- accepts a manual current latitude/longitude
- can optionally use browser geolocation
- calculates go-to information for a waypoint
- calculates nearest-path / cross-track information for routes and tracks
- follows map selection so a clicked waypoint/path can become the navigation target

Browser geolocation is optional and does not introduce an external map or provider dependency.

## Persistence and privacy

M1.22 introduces no new persistent file format. Existing `/data/waypoints.json` and `/data/paths.json` are only read by the navigation calculation. Core navigation calculations remain local and require no API key or network provider.

## Qualification

Coverage includes:

- nearest point on a route edge
- waypoint field navigation
- track nearest-point and cross-track result
- target validation
- HTTP success and bad-input cases
- static UI asset coverage
