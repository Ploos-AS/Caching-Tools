# M1.16 — Persistent mystery workspaces

Status: implemented.

M1.16 adds a provider-neutral local workspace for one mystery/multicache case. Workspaces are stored in `/data/mystery-workspaces.json` using the same atomic temp-file/rename persistence pattern as waypoints and paths.

A workspace can contain:
- optional GC code
- title
- free-form notes
- A–Z numeric variables
- intermediate result lines
- latitude and longitude final-coordinate formulas
- an optional saved final waypoint ID
- created/updated timestamps

API:
- `GET /api/mystery-workspaces`
- `POST /api/mystery-workspaces`
- `GET /api/mystery-workspaces/{id}`
- `PUT /api/mystery-workspaces/{id}`
- `DELETE /api/mystery-workspaces/{id}`

The web UI can create, edit and delete workspaces. It keeps final formulas and the final-waypoint reference together with the puzzle notes and variables. No provider account, external service or network access is required.
