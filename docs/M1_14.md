# M1.14 — Mystery / puzzle helpers

M1.14 adds small, offline-first helpers for common geocaching mystery workflows.

## Available helpers

- A1Z26 / letter values (`A=1` through `Z=26`) with per-letter values and total sum.
- Caesar / ROT shifts with positive or negative shifts.
- Digit sum and digital root/checksum.
- Simple monoalphabetic substitution with configurable source alphabet and mapping.

## API

`POST /api/puzzle`

The request uses an `operation` field plus operation-specific inputs. Supported operations are `a1z26`, `caesar`, `digitsum` and `substitution`.

## UI

The main web UI exposes all four helpers. Processing stays inside Caching Tools; no provider account, API key, CDN or external service is needed.
