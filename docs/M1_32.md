# M1.32 — Field-note search, filters and export

M1.32 extends the persistent local field-notes/logbook workflow from M1.31 with local search, filtering and explicit export.

## Search and filters

The field-notes UI can filter the already loaded local note set by:

- free-text search across title, body, status, type, local reference IDs and occurrence time,
- exact status,
- exact type,
- linked waypoint,
- linked mystery workspace.

Status and type filter choices are derived from the current local note set. Waypoint and workspace filters reuse the existing local reference APIs.

Filtering is performed in the browser. It does not modify `/data/field-notes.json` and does not require a new backend query API.

## Export

Two explicit export actions operate on the currently filtered result set:

- **JSON** — versioned bundle with format `caching-tools-field-notes`, version `1`, UTC export timestamp and the selected note objects.
- **CSV** — columns for note ID, occurrence time, title, status, type, body, waypoint/workspace references and created/updated timestamps.

CSV fields are quoted and embedded quotes are doubled. Downloads are generated locally with browser `Blob` object URLs.

Export is read-only. It does not delete, migrate or rewrite the persistent field-note store.

## Persistence compatibility

M1.32 does not change the M1.31 field-note schema or file format. Existing `/data/field-notes.json` files remain directly compatible.

## Qualification

The static UI regression verifies search/filter controls, JSON/CSV generation, escaping helpers, browser download primitives and the M1.32 milestone marker. Existing field-note store/API tests continue to qualify persistence and CRUD independently.
