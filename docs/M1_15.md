# M1.15 — Extended mystery / puzzle helpers

M1.15 expands the provider-neutral, local-first geocaching puzzle toolbox.

## Added helpers

- Morse encode/decode for A-Z and 0-9
- Bacon cipher encode/decode using five-character A/B groups
- ROT47 for printable ASCII
- Base conversion between bases 2 and 36, including multiple whitespace-separated values
- Telephone keypad values using the classic 2-9 letter mapping

These complement the M1.14 helpers for A1Z26, Caesar/ROT, digit sum/digital root and configurable substitution.

## API

All helpers continue to use `POST /api/puzzle` with an `operation` field. New operations are:

- `morse-encode`
- `morse-decode`
- `bacon-encode`
- `bacon-decode`
- `rot47`
- `base` with `from_base` and `to_base`
- `keypad`

Invalid Morse symbols, malformed Bacon groups, unsupported bases and invalid digits return HTTP 400 rather than silently producing misleading puzzle output.

## Offline / privacy properties

No external cipher service, CDN, provider account or API key is used. Puzzle text is processed inside the Caching Tools container and is not sent to third-party services.

## Tests

M1.15 adds unit round-trip tests, invalid-input coverage, HTTP API coverage and static UI/asset regression checks.

## Next

A natural next milestone is a persistent mystery workspace that can keep puzzle notes, variables, intermediate results and a solved final together without introducing a provider dependency.
