# M1.51 — field-session persistence and recovery

M1.51 protects the current in-memory field session from an ordinary page refresh or browser crash without automatically restarting GPS/geolocation.

## Recovery snapshot

A versioned snapshot is stored in browser local storage under:

`caching-tools.field-session.v1`

The snapshot contains:

- live breadcrumbs, including recording-segment IDs;
- manual field markers, including promoted-waypoint IDs;
- paused/recording state;
- current recording segment ID;
- snapshot timestamp.

Snapshots are refreshed after accepted breadcrumb points, pause/resume changes, marker creation/clear and successful marker promotion.

## Safe reload behavior

On page load Caching Tools validates any saved recovery snapshot. A valid snapshot is announced as recoverable, but its points are not inserted automatically and GPS is not restarted.

The user explicitly chooses either:

- **Restore recovered session** — restore breadcrumbs, markers, paused state and segment state;
- **Discard recovered session** — remove the recovery snapshot.

Restoring refreshes the local live-session map overlay when available. Live GPS remains stopped until explicitly started.

Starting a new live navigation session deliberately starts clean and clears an older recovery snapshot.

## Validation and limits

Malformed or unsupported recovery snapshots are discarded. Recovery is capped at 10,000 breadcrumb points and 500 manual markers during restore. Local-storage access and quota failures are handled as non-fatal conditions.

This is browser-local crash/reload recovery, not server-side synchronization or long-term archival storage. GPX remains the explicit portable export format for a field session.

## Qualification

Browser runtime tests cover:

- autosave after accepted breadcrumb points;
- pause/resume and marker persistence;
- reload detection without automatic GPS restart;
- explicit restore of points, markers, pause and segment state;
- explicit discard and clean new-session semantics;
- malformed snapshot rejection.
