# M1.45 — browser runtime tests for map overlays and field navigation

M1.45 extends the browser-side runtime qualification introduced in M1.44 from loader/list orchestration into the local SVG map overlay and field-navigation integration.

## Runtime scope

The Node 24 `node:test` suite now executes the real `cmd/caching-tools/web/map-overlays.js` source inside a small dependency-free fake-DOM harness.

The tests cover:

- waypoint map selection rendering the current-position marker;
- current-position to selected-waypoint guidance line;
- waypoint arrival-radius rendering;
- waypoint labels after local waypoint refresh;
- the `navigateField` wrapper installed by `map-overlays.js`;
- route/track current-position to nearest-path cross-track overlay;
- nearest-path marker;
- nearest-path to next-point forward segment;
- next-point marker and arrival-radius ring;
- dynamic route status class such as `off-route`;
- cross-track, remaining-distance and forward-bearing status text;
- stale navigation overlay removal when map selection changes to another object;
- rerender after `caching-tools:map-rendered`.

## Test architecture

No npm package, browser download, jsdom or Playwright is required. The test harness supplies only the DOM and event primitives used by the production script, plus a deterministic schematic map projection and local API/navigation stubs.

This keeps the qualification fast and offline-friendly while testing actual browser-side JavaScript execution instead of only static source strings.

## CI

The existing `Browser runtime tests` CI step runs:

```sh
node --test tests/browser/*.test.mjs
```

M1.45 therefore joins the existing Go test, vet and build gates without introducing a package-lock or frontend dependency tree.
