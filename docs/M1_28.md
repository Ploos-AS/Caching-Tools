# M1.28 — Breadcrumb quality controls

M1.28 hardens live-navigation breadcrumb recording against normal browser GPS noise without changing persistence or the field-navigation API.

## Recording controls

The live field-navigation UI now has two in-memory breadcrumb filters:

- **Minimum breadcrumb distance** — default 3 m. A new browser geolocation sample is not added to the breadcrumb track when it is closer than this threshold to the last accepted breadcrumb.
- **Maximum GPS accuracy** — default 50 m. Samples with missing/non-finite accuracy or browser-reported accuracy worse than this threshold are not added to the breadcrumb track.

Rejected samples still remain usable as the current live navigation position: the filters control breadcrumb recording, not the M1.24/M1.25 navigation calculation itself.

The UI reports accepted points plus separate accuracy- and distance-rejection counters. Counters reset when a new live session starts or breadcrumbs are explicitly cleared.

Because filtering happens before accepted breadcrumbs enter `liveBreadcrumbs`, M1.27 session distance and speed statistics automatically operate on the quality-filtered track.

## GPX export simplification

M1.26 GPX export remains explicit. M1.28 adds an optional **Simplify GPX export** toggle and a tolerance in metres, default 5 m.

When enabled, a local Ramer–Douglas–Peucker-style simplification is applied to a copy of the accepted breadcrumb array immediately before GPX serialization. The first and last points are retained. Original in-memory breadcrumbs are not modified.

Point-to-segment distance uses a local tangent-plane approximation suitable for ordinary GPS hobby tracks. No external geospatial service or library is used.

The export status reports the original and simplified point counts and the selected tolerance.

## Privacy and persistence

M1.28 introduces no server-side state and no schema migration.

- breadcrumb data remains browser-memory only;
- rejected samples are not stored;
- simplified export points exist only while constructing the requested GPX file;
- nothing is written automatically to `/data`;
- no provider account, API key, map service or CDN is required.

## Qualification

M1.28 is covered by static asset regression checks for the quality-control UI, recording filters, simplification helper, GPX wrapper and dynamic asset loading.
