# M1.11 — Coordinate intersections

M1.11 adds local spherical intersection solvers for common GPS and geocaching field geometry.

## Included

- bearing/bearing intersection from two independent origins and true bearings
- bearing/distance intersection between a forward bearing ray and a distance circle
- circle/circle intersection with zero, one or two solutions
- DD, DMM and DMS coordinate input through the existing parser
- DD, DMM and DMS formatted solutions
- JSON APIs and browser UI
- no provider, account, network or API-key dependency

## API

- `POST /api/coordinates/intersection/bearing-bearing`
- `POST /api/coordinates/intersection/bearing-distance`
- `POST /api/coordinates/intersection/circle-circle`

All calculations use the same spherical Earth model as the existing distance, bearing and projection tools (`R = 6371008.8 m`). Bearings are true bearings and distances/radii are metres.

## Error handling

The solvers reject degenerate or impossible geometry, including coincident origins, collinear/diverging bearing rays, negative/non-finite radii, concentric/coincident circles and non-intersecting circles.

## Deferred

- uncertainty/error bands
- magnetic declination handling
- intersections against saved waypoint/path objects directly
- saving an intersection result as a waypoint with one click
