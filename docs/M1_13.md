# M1.13 — Final coordinate formula solver

Status: implemented.

M1.13 adds a local geocaching mystery/multicache final-coordinate solver. It accepts variables A–Z and expands arithmetic expressions embedded in normal DD, DMM or DMS coordinate text.

## Formula syntax

Expressions are written inside square brackets. Example:

- Variables: `A=1, B=2, C=4, D=5, E=6`
- Latitude: `N 59 54.[A+B][C][D]`
- Longitude: `E 010 45.[E][B][A]`
- Result: `N 59 54.345, E 010 45.621`

Supported arithmetic operators are `+`, `-`, `*`, `/`, `%`, unary plus/minus and parentheses. Variables are case-insensitive single letters A–Z.

The expression engine is implemented in Go and does not use JavaScript `eval()` or an external expression package. After substitution, the result is parsed by Caching Tools' existing coordinate parser, so the same latitude/longitude validation applies.

## API

`POST /api/coordinates/final`

The request contains `variables`, `latitude_formula` and `longitude_formula`. The response contains the expanded coordinate strings plus the canonical point representation in decimal degrees, DMM and DMS.

Errors such as undefined variables, invalid assignments, division/modulo by zero, malformed expressions and invalid resulting coordinates are rejected.

## Web UI

The final-coordinate form provides:

- A–Z variable assignments
- latitude and longitude formulas
- live recalculation while editing
- DD, DMM and DMS output
- expanded coordinate text for verification
- `Save final as waypoint`

Saved finals use the existing waypoint store with type `final`; no new persistence format is introduced. Saving refreshes both the waypoint list and the local map.
