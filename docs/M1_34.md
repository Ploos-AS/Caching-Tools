# M1.34 — Local logbook dashboard

M1.34 adds a browser-local summary dashboard for the persistent field-note logbook.

## Scope

The dashboard is read-only. It loads existing local data from:

- `GET /api/field-notes`
- `GET /api/waypoints`
- `GET /api/mystery-workspaces`

It does not add a persistence file, change the field-note schema, or send telemetry to an external service.

## Dashboard metrics

The dashboard shows:

- total field-note count
- notes in the last 7 days
- notes in the last 30 days
- latest valid `occurred_at` timestamp
- status distribution
- type distribution
- activity by UTC month for the last six months
- most-used linked waypoints
- most-used linked mystery workspaces

Unset status/type values are reported explicitly as `(unset)`.

Waypoint and workspace IDs are resolved to current local display names when possible; stale soft references remain visible by ID.

## Refresh behavior

The dashboard can be refreshed explicitly. It also observes changes to the rendered field-note list and refreshes after local logbook CRUD/import activity updates that list.

All aggregation is calculated in the browser from local API responses.

## Privacy

There is no external analytics, map provider, telemetry endpoint, CDN, or provider API involved in dashboard generation.
