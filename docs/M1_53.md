# M1.53 — portable field-session bundle

M1.53 adds an explicit JSON bundle for moving a live field session between browsers or devices without reducing it to GPX.

## Scope

The field-session UI now provides:

- `Export session JSON`;
- `Import session JSON`;
- a versioned provider-neutral bundle format.

The bundle contains:

- accepted breadcrumbs, including `recordingSegment` boundaries;
- manual field markers and marker metadata;
- breadcrumb pause state;
- current recording segment ID;
- export timestamp;
- current target label as informational metadata;
- generator/version metadata.

## Format

Top-level identity:

```json
{
  "kind": "caching-tools.field-session",
  "version": 1,
  "exportedAt": "...",
  "session": {},
  "metadata": {}
}
```

The format is intentionally separate from browser crash-recovery storage. Recovery snapshots are short-lived browser-local state; portable bundles are explicit user-created files.

## Import semantics

Import is an explicit replacement of the current in-memory field session. A valid bundle replaces breadcrumbs, markers, pause state and segment state, then refreshes statistics, autosave and map overlays.

Import never starts browser geolocation automatically. The user must explicitly start live GPS navigation after import.

Imported marker promotion state is preserved when present, but no new persistent waypoint is created during import.

## Validation and limits

- bundle kind must be `caching-tools.field-session`;
- format version must be `1`;
- breadcrumbs and markers must pass the existing recovered-point validation;
- maximum 10,000 breadcrumbs;
- maximum 500 markers;
- JSON import/export is limited to 4 MiB;
- invalid or unsupported bundles are rejected without mutating the current session.

## Local-first behavior

Export/import uses browser files only. No provider API, cloud service or server-side persistence is required.

## Acceptance

- export object preserves breadcrumbs, markers, pause state and segment ID;
- metadata identifies the bundle and current target;
- explicit import replaces the in-memory session;
- import refreshes statistics, recovery autosave and map overlays;
- import does not start GPS;
- malformed/unsupported bundles are rejected;
- oversized files are rejected before parsing;
- browser runtime tests cover format, import and validation;
- Go tests, browser runtime tests, vet and build remain green.
