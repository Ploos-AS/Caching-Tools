# M1.41 — route/track navigation overlays

M1.41 extends the local SVG map with visual guidance for saved routes and tracks, using the same field-navigation response already used by the text guidance UI.

## Scope

When route/track guidance is enabled and field navigation returns a path result, the map can show:

- current field-navigation position;
- a cross-track line from the current position to the nearest point on the selected route/track;
- a marker for that nearest path point;
- a forward line from the nearest point to the next path point;
- a marker for the next path point;
- the configured arrival radius around the next point;
- a compact status label with navigation state, cross-track distance, remaining distance and forward bearing.

Supported navigation states are the existing backend states: `on-route`, `off-route`, `next-point-arrival` and `arrived`.

## Integration

`map-overlays.js` wraps the existing browser `navigateField()` function after `field-navigation.js` has loaded. It records the successful response for visualization and then returns the unchanged response to the existing navigation UI. This avoids an additional navigation API request and keeps map/text guidance based on the same calculation result.

Changing map selection clears a cached guidance result when it no longer matches the selected object.

## Semantics

M1.41 does not change backend navigation calculations, thresholds, arrival precedence, cross-track geometry or path-progress semantics. It only visualizes fields already present in `fieldNavigationResponse`.

The local map remains schematic. Visual distances and circles are aids, not survey-grade cartography.

## Privacy

No external map tiles, CDN assets, provider APIs, telemetry or persistence are added. Guidance remains local.

## Acceptance

- route/track guidance can be toggled independently;
- successful manual and live field navigation feed the same overlay result;
- nearest path point and current-to-path cross-track line are visible;
- next path point and forward segment are visible;
- arrival radius follows the existing field-navigation value;
- status styling distinguishes off-route, arrived and next-point-arrival states;
- overlay label exposes cross-track distance, remaining distance and forward bearing;
- Go tests, vet and build remain green.
