# M1.9 — Local SVG map

Status: implemented.

M1.9 adds an offline schematic map for locally stored GPS data.

## Included

- render saved waypoints as markers
- render saved routes as polylines
- render saved tracks with segment boundaries preserved
- automatically fit the view to all saved coordinates
- hover titles for waypoint and path names
- manual Refresh map action
- responsive SVG rendering
- no external map tiles, CDN, API key or provider account
- compatibility with the existing persisted path JSON representation

## Data sources

The browser reads existing local APIs only:

- `GET /api/waypoints`
- `GET /api/paths`
- `GET /api/paths/{id}` for full geometry

No new persistence format is introduced.

## Map semantics

This first map is intentionally schematic rather than a geographic basemap. Latitude and longitude are projected into the local SVG viewport using the bounding box of the currently saved data.

Track segments remain separate SVG polylines so recording gaps are not visually connected. Routes are rendered as continuous route polylines and waypoints as markers.

## Why no online basemap yet

Core Caching Tools functionality is intended to remain useful offline. Using a third-party tile service by default would add a network dependency, usage-policy concerns and potentially expose viewed locations. A future milestone can add an optional self-hosted or explicitly configured tile source without changing the local-data model.
