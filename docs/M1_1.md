# M1.1 — Waypoint projection

Status: implemented

## Goal

Add a core GPS/geocaching operation: project a destination waypoint from a known coordinate, true bearing and distance.

## Acceptance criteria

- [x] Accept a start coordinate in DD, DMM or DMS through the existing parser.
- [x] Accept true bearing in degrees.
- [x] Accept non-negative distance in metres.
- [x] Calculate the destination point using a great-circle model.
- [x] Normalize the resulting longitude.
- [x] Return the destination in DD, DMM and DMS.
- [x] Expose `POST /api/coordinates/project`.
- [x] Provide a usable web form.
- [x] Test round-trip distance/bearing and longitude normalization.
- [x] Test the HTTP projection endpoint and invalid negative distance.
- [x] Require no provider account, API key or network service.

## Scope note

Caching Tools is a toolbox for geocaching and GPS hobbyists, not a client tied to one commercial geocaching provider. Provider integrations remain optional future additions.

## Next

The next coordinate-format milestone should add UTM/MGRS support, followed by waypoint/GPX fundamentals.
