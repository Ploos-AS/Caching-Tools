# M1.2 — UTM and MGRS

Status: implemented

## Goal

Add grid-coordinate tools useful to geocachers, handheld-GPS users and map users without relying on an external provider.

## Acceptance criteria

- [x] Convert WGS84 latitude/longitude to UTM.
- [x] Convert UTM back to WGS84 latitude/longitude.
- [x] Generate 1 m precision MGRS references from WGS84 coordinates.
- [x] Handle standard UTM latitude limits (80°S to 84°N).
- [x] Handle the Norway UTM zone exception.
- [x] Handle the Svalbard UTM zone exceptions.
- [x] Validate UTM zone, hemisphere, easting and northing.
- [x] Expose grid conversion through JSON HTTP APIs.
- [x] Provide web UI for both WGS84 → grid and UTM → WGS84.
- [x] Cover known reference coordinates, round trips, special zones and HTTP behavior with Go tests.
- [x] Keep the implementation local and API-key free.

## API

- `POST /api/coordinates/grid`
- `POST /api/coordinates/from-utm`

## Datum

M1.2 uses WGS84, matching the normal datum used by consumer GPS receivers and geocaching coordinates.

## Deferred

- MGRS text parsing back to WGS84
- other datums
- UPS for polar regions outside UTM coverage
- persistent waypoint storage
- GPX import/export

The next milestone should build waypoint fundamentals on top of the coordinate engine so users can retain, name and export useful GPS positions.
