# M1.5 — GPX tracks and routes

Status: implemented.

M1.5 extends GPX 1.1 support from waypoint exchange to local inspection of routes and tracks.

## Included

- parse GPX 1.1 `<rte>` routes
- parse GPX 1.1 `<trk>` tracks and `<trkseg>` segments
- validate route and track point latitude/longitude
- summarize route name, point count and total distance
- summarize track name, segment count, point count and total distance
- preserve track segment boundaries when calculating distance
- report GPX creator, version and waypoint count
- `POST /api/gpx/inspect`
- browser GPX inspection before waypoint import
- no provider account, API key or network dependency

## Distance semantics

Routes are measured by connecting consecutive route points.

Tracks are measured inside each GPX track segment. The last point of one segment is not connected to the first point of the next segment, avoiding artificial distance across recording gaps.

Distances use the same spherical great-circle calculation as the existing navigation toolbox.

## Persistence

M1.5 is intentionally inspection-only for routes and tracks. The existing local waypoint persistence format under `/data` is unchanged. GPX waypoint import/export from M1.4 remains available.

## Deferred

- timestamps, duration and moving-speed statistics
