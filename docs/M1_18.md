# M1.18 — Mystery workspace export/import

M1.18 makes a mystery workspace portable between Caching Tools installations without changing the persistent workspace store format.

## Bundle format

A bundle is UTF-8 JSON with:

- `format: "caching-tools-mystery"`
- `version: 1`
- export timestamp
- provider-neutral workspace content: code, title, notes, A–Z variables, intermediate results and final formulas
- optional embedded final waypoint

Local workspace IDs, timestamps and local waypoint IDs are not exported.

## API

- `GET /api/mystery-workspaces/{id}/export`
- `POST /api/mystery-workspaces/import`

Import always creates a new workspace with a new local ID. If the bundle contains a final waypoint, that waypoint is recreated with a new local waypoint ID and the imported workspace is linked to it.

## UI

Each workspace has an **Export JSON** action. The workspace integration panel accepts a `.json` bundle for import.

## Failure behavior

- unknown format/version is rejected
- malformed workspace data is rejected before workspace creation
- invalid bundled waypoint data is rejected
- if workspace creation fails after creating a bundled waypoint, the newly-created waypoint is removed

## Compatibility

`/data/mystery-workspaces.json` remains unchanged; no migration is required.

## Acceptance

- [x] portable versioned JSON bundle
- [x] export one workspace
- [x] optional final-waypoint inclusion
- [x] import as a new workspace
