# M1.38 — Attachment previews and metadata

M1.38 enriches local field-note attachments without changing the field-note schema or adding external services.

## Metadata

Each attachment now exposes derived metadata calculated from the stored bytes:

- SHA-256 checksum
- size
- preview kind (`image`, `pdf`, `text`, or `none`)
- text line count for UTF-8 text-like files
- PDF version when a `%PDF-x.y` header is present

New uploads persist these fields in the attachment sidecar metadata. Existing M1.36/M1.37 attachment sidecars remain compatible: list/get derives the metadata from the local binary file even if older sidecars do not contain the new fields.

## Preview API

`GET /api/field-notes/{note-id}/attachments/{attachment-id}/preview`

Preview is separate from normal download. The regular attachment endpoint continues to return `Content-Disposition: attachment`.

The preview endpoint uses `Content-Disposition: inline`, `X-Content-Type-Options: nosniff`, and only serves content types already allowed by the attachment subsystem.

Supported preview classes:

- images: full local image response
- PDF: local inline PDF response
- text-like data: UTF-8 response capped at 64 KiB for preview

No external CDN, thumbnail service, OCR service, map provider, or telemetry is used.

## UI

The attachment UI now displays:

- SHA-256
- MIME type and size
- preview classification
- line count for text files
- PDF version when available

A **Preview** button opens a local inline preview for supported types. Image previews are constrained to the page, PDF previews use a local iframe, and text previews render into a `<pre>` element.

## Backup compatibility

M1.37 ZIP archives remain compatible. Restore still recreates attachments through the normal attachment store, so SHA-256 and derived metadata are recomputed from restored bytes instead of trusting archived metadata.

## Qualification

M1.38 adds regression coverage for checksum generation, derived text/PDF metadata, bounded text previews, inline preview headers, normal attachment-download headers, and preview UI assets.
