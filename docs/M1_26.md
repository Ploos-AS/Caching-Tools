# M1.26 — Live session GPX export

M1.26 adds explicit GPX 1.1 export for the ephemeral breadcrumb trail collected during M1.25 live navigation.

## Scope

- Export the current in-memory breadcrumb session as one GPX 1.1 track.
- One `<trk>` with one `<trkseg>`.
- One `<trkpt>` per breadcrumb, with latitude, longitude and timestamp.
- Use the currently selected navigation target in the track name.
- XML-escape the generated track name.
- Download locally from the browser using `Blob` and an object URL.
- Generate a timestamped filename such as `caching-tools-session-20260908-001234.gpx`.
- Reject export when there are no breadcrumb points.
- Keep browser-reported accuracy visible in the live session UI, but do not invent a non-standard GPX accuracy extension.

## Privacy and persistence

The breadcrumb list remains browser-memory-only. Export is an explicit user action and does not write the session into `/data`, `paths.json`, or any other persistent Caching Tools store.

Starting a new live session still clears the breadcrumb list. Page reload still discards it unless the user exported the GPX file first.

## GPX shape

```xml
<gpx version="1.1" creator="Caching Tools" xmlns="http://www.topografix.com/GPX/1/1">
  <trk>
    <name>Caching Tools session - …</name>
    <trkseg>
      <trkpt lat="…" lon="…"><time>…</time></trkpt>
    </trkseg>
  </trk>
</gpx>
```

## Acceptance

- `Export session GPX` is available beside the breadcrumb controls.
- Empty-session export is rejected with a visible status message.
- Export uses GPX 1.1 namespace and track structure.
- Session timestamps are preserved as GPX `<time>` values.
- Export is entirely client-side.
- No persistence schema or API changes are required.
- Existing live-navigation behavior remains unchanged.
